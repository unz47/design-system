## aria-sort を忘れない

並び替えができる列には `aria-sort`(`ascending` / `descending` / `none`)を付ける。矢印だけでは、支援技術に「今どの列で並んでいるか」が伝わらない。

## 0件のときは EmptyState に切り替える

ヘッダだけのテーブルが残ると「読み込み中なのか、該当が無いのか」が分からない。行が無いときは表ごと `EmptyState` に置き換える。
