Command は画面中央に出るコマンドパレット(⌘K)。

## cmdk を使わない

計画では cmdk を想定していたが、**cmdk は内部で Radix に依存**しており「Radixは不採用」という方針と衝突する。Base UI の Combobox が絞り込みとキーボード操作をすでに持っているので、それを画面中央のパネルとして出すだけで足りる。

つまり **Combobox との違いは器だけ**で、中身の仕組みは同じ。Combobox は入力欄に紐づく候補リスト、Command は画面全体を覆うパレット。

## 開閉は自分で持つ

`⌘K` を拾うのはアプリ側の責任なので、`open` / `onOpenChange` を制御する。ショートカットの登録までこのコンポーネントに入れると、消費側がキーバインドを変えられなくなる。

パレットにしか無い操作を作らないこと。キーボードを使わないユーザーが到達できなくなる。
