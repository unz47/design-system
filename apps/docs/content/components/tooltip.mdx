Tooltip はホバー/フォーカスで出る短い補足。**面ではなく札**なので、Popover や Dialog より一段軽い見た目(`bg.raised` + `elevation-2`)にしている。

## Provider をルートに置く

`TooltipProvider` をアプリのルートに1つ置くと、複数のツールチップで遅延が共有され、2つ目以降が即座に開く。1つずつ遅延すると、並んだアイコンを撫でるたびに待たされる。

## 中に操作を置かない

Tooltip はフォーカスを受け取らないので、中にボタンやリンクを置くとキーボードから到達できない。操作が要るなら Popover を使う。

タッチ端末にはホバーが無いため、Tooltip だけが情報源になっている状態を作らないこと。
