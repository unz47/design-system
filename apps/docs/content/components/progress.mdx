Progress は進捗の表示。`value` は**必須**で、`null` を渡したときだけ不確定(indeterminate)になる。省略はできない。

Base UI がこの設計にしているのは、「まだ値が来ていない」と「値が無い状態」を取り違えないため。`value={data?.percent ?? null}` のように、呼び出し側で必ず意図を書くことになる。

「何%終わったか分かる」なら Progress、「終わりが読めない」なら Spinner を使う。不確定な Progress バーは、ユーザーには「動いているが終わらないもの」に見えるため、長い待ちには向かない。

`aria-valuenow` などのARIA属性は Base UI が付けるので、こちらでは何もしていない。
