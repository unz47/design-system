Label はフォーム部品の見出し。素の `<label>` を描画する。

Base UI にも `Field.Label` があるが、あちらは `Field.Root` の文脈を必要とする。単独で使える薄い `<label>` をここに置き、Field と組んでバリデーションまで面倒を見たい場面では Base UI 側を直接使う、という住み分けにしている。

`htmlFor` で結ぶのが基本。入力を包む書き方(`<Label><Input /></Label>`)でも動くが、`htmlFor` のほうが DOM 構造の自由度が高い。

`peer-disabled:` で不透明度が落ちるようにしてあるので、入力側に `peer` クラスを付ければ無効状態が連動する。
