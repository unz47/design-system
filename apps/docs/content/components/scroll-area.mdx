ScrollArea はスクロール可能な領域に、OSに依存しない見た目のスクロールバーを付ける。

## 常時表示にしない

スクロールバーは `data-hovering` / `data-scrolling` のときだけ不透明にしている。常時表示にすると、macOS のオーバーレイスクロールバーと二重に見える。

## 横スクロール

既定は縦だけ。横も出したい場合は `horizontal` を付ける。両方出すと Base UI が角の `Corner` を要求する場面があるが、この構成では重ならないので置いていない。

高さは自分では持たないので、`className` で `h-40` のように指定する。高さが無いと中身がそのまま伸びてスクロールしない。
