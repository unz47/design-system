Badge は状態やカテゴリを示す小さなラベル。atom。

`default` はニュートラルな分類ラベル、`accent` はブランドアクセントの強調、`success` / `danger` / `warning` / `info` はステータス色の `subtle-bg` + `solid` の組み合わせで、背景を薄く・文字を濃くすることでコントラストを確保している。

## クリックできる見た目にしない

Badge は `<span>` を描画するだけで、フォーカスもキーボード操作も持たない。押せるものが欲しい場合は Badge に `onClick` を足すのではなく Button(または Toggle)を使うこと。

## ステータス色の内訳はテーマで反転する

dark では「暗い `subtle-bg` の上に明るい `solid` の文字」、light では「淡い `subtle-bg` の上に濃い `solid` の文字」になる。同じトークン名で参照先が入れ替わる設計なので、コンポーネント側の記述は1つで済んでいる。
