RadioGroup は排他選択。`RadioGroup` と `Radio` の2つで構成する。

選択肢は消費者が並べるものなので、Switch のように1つのコンポーネントには畳んでいない。ただし `Radio` 単体は Root + Indicator を畳んであるので、消費側が書くのは1階層で済む。

矢印キーでの移動・タブ順(グループ全体で1つ)は Base UI が持つ。

**`orientation` prop は無い**(Base UI の RadioGroup は受け取らない)。横に並べたい場合は `className="flex-row"` を渡す。variants 側は `data-orientation` でも分岐できるようにしてあるが、その属性が付くのは Base UI が出したときだけ。

各 Radio は `id` + `Label htmlFor` で結ぶ。
